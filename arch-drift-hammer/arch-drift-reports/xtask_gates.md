## 3. Violations

### 🔴 HIGH: Thin Wrapper Boilerplate (Lines 93–146)

**18 identical functions** that all delegate to `run_named_gate`:

```rust
pub fn run_fmt_gate(bead_id: Option<&str>) -> Result<GateEvidence> {
    run_named_gate(Gate::Fmt, bead_id)
}
pub fn run_check_gate(bead_id: Option<&str>) -> Result<GateEvidence> {
    run_named_gate(Gate::Check, bead_id)
}
// ... 14 more identical patterns ...
```

**Problem**: This is mechanical duplication. Every `run_*_gate` function:
1. Takes the same signature: `(Option<&str>) -> Result<GateEvidence>`
2. Calls `run_named_gate` with the corresponding `Gate` variant

**DDD Smell**: Feature Envy + Data/Behavior mismatch. These functions have no behavior of their own—they just route to a shared service.

**Fix**: Replace all 18 with a single:
```rust
pub fn run_gate(gate: Gate, bead_id: Option<&str>) -> Result<GateEvidence> {
    run_named_gate(gate, bead_id)
}
```

Callers would use `run_gate(Gate::Fmt, bead_id)` instead of `run_fmt_gate(bead_id)`.
