### 2.1 Raw `i64` for Arbitrary Operands
**Severity**: 🔴 CRITICAL

The file uses `any::<i64>()` directly in proptest! generators. This is primitive obsession — the domain of constant folding has specific integer subsets that should be modeled:

```rust
// VIOLATION (Lines 41, 135, 147, 159, 171, 190, 199, 208, 217, 226, 235, 250, 328)
```

**Required NewTypes** (per Wlaschin `Make Illegal States Unrepresentable`):
- `NonZeroI64` — for division/modulo operands (b != 0)
- `I64Operand` — for general arithmetic operands
- `I64Min` — sentinel for overflow edge case testing

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct VariableName(String);

impl VariableName {
    pub fn parse(s: &str) -> Option<Self> {
        let s = s.strip_prefix('$')?;
        if s.chars().next()?.is_ascii_lowercase()
            && s.chars().all(|c| c.is_ascii_lowercase() || c.is_ascii_digit() || c == '_')
            && s.len() <= 20
        {
            Some(Self(s.into()))
        } else {
            None
        }
    }
}

impl Arbitrary for VariableName {
    type Parameters = ();
    type Strategy = BoxedStrategy<Self>;
    fn arbitrary_with(_: Self::Parameters) -> Self::Strategy {
        "[a-z][a-z0-9_]{1,20}"
            .prop_map(|s| Self::parse(&format!("${}", s)).unwrap())
            .boxed()
    }
}
```
