## Summary of Fixes Applied

### Issue 1: `replay()` Returns All TRACKER Entries (LETHAL) — FIXED

**File**: `crates/vb_cli/src/lifecycle.rs` (lines 477-489)

**Problem**: `replay()` iterated `tracker.states.iter()` which contained ALL runs ever tracked, not just runs from the current journal.

**Fix Applied**:
```rust
// BEFORE: Returned all TRACKER entries (polluted by previous tests)
let states: Vec<RunState> = tracker
    .states
    .iter()
    .map(|(&run_id, &lifecycle)| RunState { ... })
    .collect();

// AFTER: Returns only journal-derived states
use std::collections::HashSet;
let journal_run_ids: HashSet<RunId> = headers.iter().map(|h| h.run).collect();
let states: Vec<RunState> = journal_run_ids
    .iter()
    .filter_map(|&run_id| {
        tracker.states.get(&run_id).map(|&lifecycle| RunState { ... })
    })
    .collect();
```

**Rationale**: Only return states for runs that exist in the current journal, preventing TRACKER pollution between tests.
