**Contract: Declared Input Resolution for Terminal Finish**

The cold compiler resolves declared inputs by binding exact `$input.name` references to numeric ports in declaration order. Inputs are represented as bounded slices of `SlotValue` via Postcard serialization. The schema shorthand accepts `number` or `{is:number}`.

During lowering, the compiler processes preceding internal nodes first. Before allocating input ports, it reserves the non-input terminal `Finish` slot using the existing `canonical_finish_slot` and `builder.record_slot` mechanisms. This reservation prevents integer slot collisions between the `Finish` node and input ports. Input ports are then bound after the largest internal index, and the `Finish` node is lowered last. This sequence ensures that the `Finish` node's internal read is reserved before input port allocation, avoiding aliasing at the numeric boundary.

If no `Finish` node is present, input ports are allocated after all nodes are processed. The layout preserves the existing internal-first port numbering scheme without renumbering. All index arithmetic uses checked addition and u16 conversion. The public `allocate_input_slots` signature remains unchanged.

At runtime, an I64 input value must produce the exact input value for the `Finish` node and any preceding save fixture. Unknown input references produce the existing `CompileError::UnknownOutputName` error with the literal `$input.missing` name. Duplicate input validation continues to run as before.

The deterministic digest and roundtrip properties are preserved. Non-finish consumers of inputs remain explicitly unsupported. This contract does not claim full v1 input support or required input defaults. Broader input use cases remain open under parent issue vb-3ruqy.
Clarification: preceding save writes its own slot; only Finish returns the external input. This child covers terminal Finish; parent vb-3ruqy remains open for non-Finish consumers.

use vb_compile::{CompileError, CompileErrors, compile_source, parse_workflow_source};
use vb_core::engine::{EngineSignal, StepBudget, new_run_frame, run_until_blocked};
use vb_core::value_store::ValueStore;
use vb_core::{
    CompiledInputSlot, CompiledNodeKind, CompiledWorkflow, InputSlotKind, RunId, SlotIdx,
    SlotValue, Taint, WorkflowParts,
};

fn compile(yaml: &str) -> Result<CompiledWorkflow, Box<dyn std::error::Error>> {
    Ok(compile_source(&parse_workflow_source(yaml)?)?)
}

fn run(
    workflow: &CompiledWorkflow,
    values: &[i64],
) -> Result<EngineSignal, Box<dyn std::error::Error>> {
    let mut frame = new_run_frame(RunId::new(1), workflow)?;
    for (port, value) in workflow.input_slots().iter().zip(values.iter()) {
        frame.write_slot_with_taint(port.slot, SlotValue::I64(*value), Taint::Secret)?;
    }
    Ok(run_until_blocked(
        workflow,
        &mut frame,
        StepBudget::MAX,
        &mut ValueStore::new(),
    )?)
}

fn test_roundtrip() -> Result<(), Box<dyn std::error::Error>> {
    let workflow = compile(BASE)?;
    let parts = workflow.to_parts();
    let serialized = postcard::to_allocvec(&parts)?;
    let restored_parts: WorkflowParts = postcard::from_bytes(&serialized)?;
    assert_eq!(parts, restored_parts);
    let recompiled = compile(BASE)?;
    assert_eq!(parts, recompiled.to_parts());
    let restored_workflow = CompiledWorkflow::try_from_parts(restored_parts)?;
    let signal = run(&restored_workflow, &[42])?;
    assert_eq!(
        signal,
        EngineSignal::Finished(SlotValue::I64(42), Taint::Secret)
    );
    Ok(())
}

use super::*;

pub(super) fn prepare_finish_input_slots(
    source: &crate::WorkflowSource,
    result: &crate::ScalarValue,
    outputs: &mut std::collections::HashMap<String, vb_core::SlotIdx>,
    builder: &mut SlotCompiler,
) -> Result<(), CompileErrors> {
    if !matches!(result, crate::ScalarValue::String(name) if name.starts_with("$input.")) {
        let internal = canonical_finish_slot(result, outputs)?;
        builder.record_slot(internal);
    }

    allocate_input_slots(source.inputs(), builder).map_err(|e| CompileErrors(vec![e]))?;

    for (input, port) in source.inputs().iter().zip(builder.input_slots.iter()) {
        let name = format!("$input.{}", input.key);
        if outputs.contains_key(&name) {
            return Err(CompileErrors(vec![CompileError::DuplicateOutputName {
                name: name.into_boxed_str(),
            }]));
        }
        outputs.insert(name, port.slot);
    }

    Ok(())
}
