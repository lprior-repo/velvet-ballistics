# Admission compatibility recovery contract

For a real storage-issued Strict artifact and Runtime admission, cold recovery retains the original admission's journaled IrVersion compatibility decision together with its artifact, input, policy, budget and grants. The shared admission hydration helper restores the factual first matching IrVersion record for the same run; an absent record remains absent and another run or compatibility boundary cannot supply it. This metadata does not grant live execution or replace compatibility enforcement over the durable history. Existing admission shape validation, artifact/grant checks, current compatibility gates, formats and public APIs remain unchanged.

The real completed-action crash-prefix tests must compare the whole recovered RunState against independently driven live state at the same Ask boundary. The only independent control differences are wall-clock origin and charged bytes from the retained explicit-resume prefix; verify these against the exact durable RunBudgetOrigin and checked sum of journal wire encodings before accounting for them in full-state comparison. Preserve all old denial, .61, receipt, sequence, full-store nonmutation and terminal exactly-once assertions. Add focused helper denial tests for foreign-run and non-IR decision records. No fabricated authority, new dependency, gate change or schema migration.
