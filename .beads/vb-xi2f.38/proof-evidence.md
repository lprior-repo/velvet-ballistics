## Bug Summary

The `digest_step_primitive` function in `crates/vb_compile/src/mod_compile_lowering/part_05.rs:140-161` uses a catch-all match arm for `StepPrimitive::Collect`:

```rust
// Lines 158-160 (BUG)
other => {
    hasher.update(canonical_primitive_name(other).as_bytes());
}
```

Only the primitive name `"collect"` is hashed; the fields `variable`, `source`, `pages`, `items`, and `body` are NOT included in the digest.
