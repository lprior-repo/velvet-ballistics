## .beads/vb-kcfc6/contract.md
**Domain:** CLI input decoder for compiled workflow execution. Decodes raw positional binary into `SlotValue` sequence, validates against declared input slots, emits mapped `(slot, value)` pairs. Non-core values (`List`, `Object`, `Blob`) are accepted; their internal structural validation is a separate parent-scope concern (vb-ezymz).

**Value Types:**
- `input_data`: `&[u8]` — raw positional input payload
- `compiled.input_slots()`: declared input slot descriptors, each with `slot: SlotIdx` and `kind: InputSlotKind`
- `SlotValue`: Null, Bool, I64, F64, Symbol, List, Object, Blob, and other core variants
- `InputMappingError`: DecodeFailed, SlotCountExceeded, SlotIndexOutOfRange, KindMismatch{slot, expected_kind}

**Workflow:**
1. Decode `input_data` as Postcard `Box<[SlotValue]>`. Empty input yields an empty list. Decoder error or trailing unused bytes yields `DecodeFailed`.
2. If decoded value count exceeds declared input slot count, return `SlotCountExceeded`.
3. Positionally map each supplied value to its corresponding declared slot:
   - Derive value kind (Null/Bool/I64/F64/Symbol/List/Object/Blob; other core variants yield `DecodeFailed`).
   - If value kind != slot's declared kind, return `KindMismatch{slot, expected_kind}`.
4. Return boxed slice of `(SlotIdx, SlotValue)` pairs. Unsupplied slots are omitted; missing values are not invented.

**Errors:**
- `DecodeFailed`: Postcard decode error, non-core value variants, or trailing unused bytes after decoding.
- `SlotCountExceeded`: More supplied values than declared input slots.
- `KindMismatch{slot, expected_kind}`: Supplied value kind does not match declared slot kind.
- `SlotIndexOutOfRange`: Existing variant remains unchanged and is not synthesized by this positional mapping repair.

**Boundaries:**
- Exactly one Postcard message per invocation; no indexed addressing, no default value generation, no runtime I/O.
- Empty input always yields empty mapping (requiredness is runtime admission, not decoder concern).
- Durability handling, non-core value validation, and durable submit persistence are unchanged parent-scope responsibilities.

**Hazards:**
- `postcard::from_bytes` ignores trailing bytes; must use `take_from_bytes` to detect remainder.
- Decode must succeed before count/kind checks; otherwise partial decode leads to misattribution.
- Current8SlotValue variants retain existing kind mapping; unsupported future shapes return DecodeFailed.

//! Module: run_compiled

use crate::app_impl::prelude::*;

pub(crate) fn cmd_run_compiled(
    vbir_path: &std::path::Path,
    input_bin: &std::path::Path,
    durability: DurabilityMode,
    db: Option<&std::path::Path>,
    output: OutputFormat,
) -> ExitCode {
    let input_data = match read_file(input_bin, output, CliExitCode::ValidationFailed) {
        Ok(b) => b,
        Err(code) => return code,
    };

    let ir_bytes = match read_file(vbir_path, output, CliExitCode::CompileFailed) {
        Ok(b) => b,
        Err(code) => return code,
    };

    let compiled: vb_core::CompiledWorkflow =
        match postcard::from_bytes::<vb_core::WorkflowParts>(&ir_bytes) {
            Ok(parts) => match vb_core::CompiledWorkflow::try_from_parts(parts) {
                Ok(c) => c,
                Err(e) => {
                    if output != OutputFormat::Text {
                        json_error(
                            &serde_json::json!({
                                "success": false,
                                "error": format!("compiled IR validation error: {e}")
                            }),
                            output,
                        );
                    } else {
                        errln!("compiled IR validation error: {e}");
                    }
                    return CliExitCode::CompileFailed.into();
                }
            },
            Err(e) => {
                if output != OutputFormat::Text {
                    json_error(
                        &serde_json::json!({
                            "success": false,
                            "error": format!("error deserializing compiled IR: {e}")
                        }),
                        output,
                    );
                } else {
                    errln!("error deserializing compiled IR: {e}");
                }
                return CliExitCode::CompileFailed.into();
            }
        };

    let inputs = match map_runtime_inputs(&compiled, &input_data) {
        Ok(inputs) => inputs,
        Err(error) => {
            if output != OutputFormat::Text {
                json_error(
                    &serde_json::json!({
                        "success": false,
                        "error": error.to_string()
                    }),
                    output,
                );
            } else {
                errln!("{error}");
            }
            return CliExitCode::CompileFailed.into();
        }
    };

    run_compiled_workflow(&compiled, inputs, durability, db, output)
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum InputMappingError {
    DecodeFailed,
    SlotCountExceeded,
    SlotIndexOutOfRange,
    KindMismatch {
        slot: vb_core::SlotIdx,
        expected_kind: vb_core::InputSlotKind,
    },
}

impl std::fmt::Display for InputMappingError {
    fn fmt(&self, formatter: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            Self::DecodeFailed => formatter.write_str(INPUT_MAPPING_DECODE_FAILED_MESSAGE),
            Self::SlotCountExceeded => formatter.write_str(INPUT_MAPPING_SLOT_COUNT_EXCEEDED_MESSAGE),
            Self::SlotIndexOutOfRange => formatter.write_str(INPUT_MAPPING_SLOT_INDEX_OUT_OF_RANGE_MESSAGE),
            Self::KindMismatch { slot, expected_kind } => write!(
                formatter,
                "INPUT_MAPPING_FAILED: slot {slot:?} value kind mismatch, expected {expected_kind:?}"
            ),
        }
    }
}

pub(crate) fn map_runtime_inputs(
    compiled: &vb_core::CompiledWorkflow,
    input_data: &[u8],
) -> Result<Box<[(vb_core::SlotIdx, vb_core::SlotValue)]>, InputMappingError> {
    let input_slots = compiled.input_slots();
    if input_data.is_empty() {
        return Ok(Box::from([]));
    }
    let (values, remainder) = postcard::take_from_bytes::<Box<[vb_core::SlotValue]>>(input_data)
        .map_err(|_| InputMappingError::DecodeFailed)?;
    if !remainder.is_empty() {
        return Err(InputMappingError::DecodeFailed);
    }
    if values.len() > input_slots.len() {
        return Err(InputMappingError::SlotCountExceeded);
    }
    input_slots
        .iter()
        .zip(values.iter())
        .map(|(slot, value)| {
            let value_kind = match value {
                vb_core::SlotValue::Null => vb_core::InputSlotKind::Null,
                vb_core::SlotValue::Bool(_) => vb_core::InputSlotKind::Bool,
                vb_core::SlotValue::I64(_) => vb_core::InputSlotKind::I64,
                vb_core::SlotValue::F64(_) => vb_core::InputSlotKind::F64,
                vb_core::SlotValue::Symbol(_) => vb_core::InputSlotKind::Symbol,
                vb_core::SlotValue::List(_) => vb_core::InputSlotKind::List,
                vb_core::SlotValue::Object(_) => vb_core::InputSlotKind::Object,
                vb_core::SlotValue::Blob(_) => vb_core::InputSlotKind::Blob,
                _ => return Err(InputMappingError::DecodeFailed),
            };
            if value_kind != slot.kind {
                return Err(InputMappingError::KindMismatch {
                    slot: slot.slot,
                    expected_kind: slot.kind,
                });
            }
            Ok((slot.slot, *value))
        })
        .collect::<Result<Vec<_>, _>>()
        .map(Vec::into_boxed_slice)
}

pub(crate) fn runtime_journal_for_mode(
    durability: DurabilityMode,
    db: Option<&std::path::Path>,
    output: OutputFormat,
) -> Result<vb_runtime::journal::SharedRuntimeJournal, ExitCode> {
    match durability {
        DurabilityMode::None => Ok(vb_runtime::journal::NoopRuntimeJournal::shared()),
        DurabilityMode::Journaled => open_storage_runtime_journal(db, false, output),
        DurabilityMode::Strict => open_storage_runtime_journal(db, true, output),
    }
}

pub(crate) fn runtime_config_for_durability(
    durability: DurabilityMode,
) -> vb_runtime::shard::ShardConfig {
    let mut config = vb_runtime::shard::ShardConfig::default();
    if durability == DurabilityMode::None {
        config.policy = vb_core::policy::RuntimePolicy::Relaxed;
    }
    config
}

use std::fs;
use std::process::Command;

const YAML_STRING: &str = "version: velvet-ballistics/v1\nname: input_boundary\nwhen:\n  manual: {}\nsteps:\n  - id: build_result\n    save:\n      output: saved\n      value: '42'\n  - id: done\n    finish:\n      result: saved\n";

#[test]
fn cli_zero_port_input_boundary() -> Result<(), Box<dyn std::error::Error>> {
    let dir = tempfile::tempdir()?;
    let yaml_path = dir.path().join("workflow.yaml");
    let ir_path = dir.path().join("workflow.ir");
    let input_path = dir.path().join("input.bin");

    fs::write(&yaml_path, YAML_STRING)?;

    let compiled = Command::new(env!("CARGO_BIN_EXE_velvet-ballistics"))
        .arg("compile")
        .arg(&yaml_path)
        .args(["--emit", "postcard", "--out"])
        .arg(&ir_path)
        .output()?;
    assert_eq!(
        compiled.status.code(),
        Some(0),
        "{}",
        String::from_utf8_lossy(&compiled.stderr)
    );

    let encoded_empty = postcard::to_allocvec(&Box::<[vb_core::SlotValue]>::from([]))?;
    let one_value = postcard::to_allocvec(&Box::<[vb_core::SlotValue]>::from([
        vb_core::SlotValue::I64(42),
    ]))?;

    let cases: [(Vec<u8>, Option<&str>); 5] = [
        (Vec::new(), None),
        (encoded_empty.clone(), None),
        (
            vec![255],
            Some("INPUT_MAPPING_FAILED: input-bin decode failed"),
        ),
        (
            one_value,
            Some("INPUT_MAPPING_FAILED: input slot count exceeds workflow slot count"),
        ),
        (
            encoded_empty.clone().into_iter().chain(vec![255]).collect(),
            Some("INPUT_MAPPING_FAILED: input-bin decode failed"),
        ),
    ];

    for (data, expected) in cases {
        fs::write(&input_path, &data)?;
        for (command, path, failure_code) in [("run", &yaml_path, 1), ("run-compiled", &ir_path, 3)]
        {
            let output = Command::new(env!("CARGO_BIN_EXE_velvet-ballistics"))
                .arg(command)
                .arg(path)
                .arg("--input-bin")
                .arg(&input_path)
                .args(["--durability", "none"])
                .output()?;

            if let Some(expected_msg) = expected {
                assert_eq!(
                    output.status.code(),
                    Some(failure_code),
                    "{command}: {}",
                    String::from_utf8_lossy(&output.stderr)
                );
                assert_eq!(String::from_utf8_lossy(&output.stderr).trim(), expected_msg);
            } else {
                assert_eq!(output.status.code(), Some(0));
                let stdout = String::from_utf8_lossy(&output.stdout);
                assert!(
                    stdout
                        .lines()
                        .any(|line| line == "run 1: submitted=1 completed=1 failed=0 steps=2"),
                    "{stdout}"
                );
                assert!(stdout.ends_with("run completed\n"), "{stdout}");
                assert!(output.stderr.is_empty());
            }
        }
    }

    Ok(())
}
