# Owner-only IPC socket binding

`IpcServer::bind` owns creation of its Unix socket. After the OS creates a fresh socket and before registering it with the reactor or returning success, set its permission bits to exactly `0600`. This enforces MASTER section59's local privilege boundary independently of caller umask. Socket ownership stays with the creating process. Existing owner access and Health request/response behavior remain valid.

Domain flow: unbound pathname -> successfully bound listener -> owner-only listener -> registered server. A failed bind never changes an existing file or socket. A permission-setting failure returns existing `IpcServerError::BindFailed` with the original I/O source; no new error, public API, authentication mechanism, protocol field, dependency or persisted format is introduced. Subsequent polling/registration errors retain their existing variants and cleanup behavior. This contract does not claim protection against an adversary concurrently replacing the pathname.

The original public scenario used frozen hardened e346 binary SHA2563131efa86abba4e7db9c171996c9eff147ccdc5375fe14475fe5ff8d63a78c85: `ipc-serve` under child umask000 became ready with mode0777, correct owner1000 and empty stderr; the expected mode0600 failed. The service was stopped after observation and original records/socket retained under r15e ignored evidence. Historical server blobs6bc094dfe89673e6b3dc7ad223d3ec1c4d4c5c84 and8d4baeb4653e84c7d6af7f439f6286d3917d0ad3 supply only this narrow useful permission intent; their other buffering/array-slot/caller-capability/peer-auth changes are not accepted here.

Behavior checks use the actual public bind in a child process with umask000, leaving the parent runner's umask untouched. Assert exact0600, creating owner, real owner Health request and response, and a refused duplicate bind preserving that listener's metadata and usability. Also assert a pre-existing regular file retains exact bytes/mode/owner on BindFailed and a missing-parent failure creates no socket or directory. Existing IPC regression cases stay unchanged. CPU/cloud only; benchmarks skipped. Independent CODE and TEST review plus parent integration gates precede landing; no proof or whole-product acceptance is inferred from focused checks.
