**Rationale:** All five failing test files use `when: "0"` (or indexed variants) as choose branch conditions, which the compiler interprets as slot index 0. The setup step in each fixture creates slot 0 with an integer value (`"1"` or `"0"`), but `canonical_choose_conditions.rs` now requires boolean-typed slots for numeric-slot conditions. The minimal fix is to change the setup `Set` value from an integer string to a YAML boolean literal (`true`), making slot 0 boolean-typed while preserving all branch targets, body steps, and assertions.
