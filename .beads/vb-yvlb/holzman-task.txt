## SHARDOWNERSHIP IMPLEMENTATION

### TLA+ Spec (specs/tla/ShardOwnership.tla)

Three state variables:
1. `run_owner: [RunId -> ShardId]` — which shard owns each run
2. `shard_runs: [ShardId -> Set[RunId]]` — reverse index
3. `pending_transfers: Set[(RunId, ShardId)]` — in-flight migrations

Three actions:
- `AssignShard(run, shard)`: run_owner[run] must be Nil; sets owner and adds to shard_runs
- `InitiateTransfer(run, new_shard)`: run_owner[run] must be != Nil and != new_shard; adds to pending_transfers
- `CompleteTransfer(run, new_shard)`: <<run, new_shard>> must be in pending_transfers; removes from old shard_runs, adds to new shard_runs, updates run_owner, removes from pending_transfers

Three invariants (THEOREMs):
- `SingleOwner`: each run has exactly one shard owner
- `RunOnExactlyOneShard`: each run appears in exactly one shard_runs set
- `NoPendingTransferConflict`: pending transfers do not conflict with current ownership

#### 4. Add Runtime methods for ownership actions

```rust
/// Assigns an unowned run to a shard. Called during submit.
/// Precondition: run is not already owned (checked via RunAlreadyOwned error).
pub fn assign_shard(&mut self, run: RunId, shard: ShardIndex) -> RuntimeResult<()> {
    if let Some(&current) = self.run_owner.get(&run) {
        return Err(RuntimeError::RunAlreadyOwned { run, owner: current });
    }
    let prev = self.run_owner.insert(run, shard);
    // prev is None means the run was unowned (correct)
    let runs = self.shard_runs.get_mut(&shard).ok_or(RuntimeError::RunNotFound)?;
    runs.insert(run);
    Ok(())
}

/// Initiates a transfer of run from its current shard to target_shard.
/// The run must already be owned and not already transferring to target_shard.
pub fn initiate_transfer(&mut self, run: RunId, target_shard: ShardIndex) -> RuntimeResult<()> {
    let current_owner = self.run_owner.get(&run).ok_or(RuntimeError::RunNotFound)?;
    if *current_owner == target_shard {
        return Err(RuntimeError::TransferSameShard { run, shard: target_shard });
    }
    let transfer = Transfer { run, target_shard };
    if self.pending_transfers.contains(&transfer) {
        return Err(RuntimeError::TransferAlreadyPending { run, target_shard });
    }
    self.pending_transfers.insert(transfer);
    Ok(())
}

/// Completes a pending transfer of run to target_shard.
/// Removes run from old shard_runs, adds to new shard_runs, updates run_owner.
pub fn complete_transfer(&mut self, run: RunId, target_shard: ShardIndex) -> RuntimeResult<()> {
    let transfer = Transfer { run, target_shard };
    if !self.pending_transfers.contains(&transfer) {
        return Err(RuntimeError::NoPendingTransfer { run });
    }
    let old_owner = *self.run_owner.get(&run).ok_or(RuntimeError::RunNotFound)?;
    // Remove from old shard
    if let Some(old_runs) = self.shard_runs.get_mut(&old_owner) {
        old_runs.remove(&run);
    }
    // Add to new shard
    if let Some(new_runs) = self.shard_runs.get_mut(&target_shard) {
        new_runs.insert(run);
    } else {
        return Err(RuntimeError::RunNotFound);
    }
    // Update owner
    self.run_owner.insert(run, target_shard);
    // Remove from pending
    self.pending_transfers.remove(&transfer);
    Ok(())
}

/// Releases ownership of a run when it terminates (complete/fail/cancel).
pub fn release_run_ownership(&mut self, run: RunId) -> RuntimeResult<()> {
    let owner = self.run_owner.remove(&run).ok_or(RuntimeError::RunNotFound)?;
    if let Some(runs) = self.shard_runs.get_mut(&owner) {
        runs.remove(&run);
    }
    // Remove any pending transfers for this run
    self.pending_transfers.retain(|t| t.run != run);
    Ok(())
}
```

#### 5. Modify `shard_index` for ownership-based routing

Replace the current `shard_index` implementation:

```rust
fn shard_index(&self, run: RunId) -> usize {
    // First check run_owner for actual ownership
    if let Some(&owner) = self.run_owner.get(&run) {
        return owner.0;
    }
    // Fallback: hash-based for unowned runs (consistent placement)
    let hash = run.get();
    let Ok(count) = u64::try_from(self.shard_count) else {
        return 0;
    };
    let Some(remainder) = hash.checked_rem(count) else {
        return 0;
    };
    let Ok(index) = usize::try_from(remainder) else {
        return 0;
    };
    index
}
```
