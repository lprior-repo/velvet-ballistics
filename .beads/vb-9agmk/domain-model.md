# Artifact domain
Compiler output is a candidate, not runtime admission authority (master 77.2).
A checked compilation binds one canonical WorkflowParts payload, its workflow
identity, source-spec bytes when supplied, resource policy, and action contracts.
A validation is an executed implementation check. External idempotency is a
contract declaration, not a proof. Durability is a successful storage action,
not a compiler property. Replay conformance requires runtime execution evidence.
The accepted artifact is an aggregate whose envelope digest binds all evidence.
