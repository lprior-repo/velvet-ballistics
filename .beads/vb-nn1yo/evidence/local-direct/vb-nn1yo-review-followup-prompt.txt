# Contract: `analyze_retry`

**Signature:** `(events: &[JournalEvent]) -> RetryAnalysis`

**Purpose:** Inspect an ordered per-run journal slice and report whether a retry is appropriate, which step failed, and the last successful step. Pure analysis; consumed by CLI report only.

## Eligibility

Only a terminal `RunFailedEvent` makes a run eligible for retry. Runs that are cancelled, finished, empty, or still active are not eligible and must preserve the existing non-failure reason literal.

## Failure Step Determination

The failure step is the latest unresolved observed `StepStarted` or `ActionFailedEvent`. A `StepSucceeded` event records the last successful step and clears any matching pending step. Do not invent a next step by adding one to a successful numeric ID: workflows branch and are not linear, and a u16 maximum boundary cannot wrap or saturate into an unobserved step.

If no unresolved step was observed, `failed_at_step` is `None`. A failed terminal run may still have `can_retry` set to `true` as an analysis report.

## Non-Failure Cases

When the run did not fail, return `failed_at_step: None`, the observed `last_successful_step`, `can_retry: false`, and the reason `"run did not fail (no retry needed)"`.

## Implementation Constraints

- Fold bounded by the event slice; no new loops
- No `unsafe`, `panic`, `unwrap`, index access, or type casts
- No execution or retry workflow side effects
- No public wire field changes

## Test Coverage

Retain the existing four tests. Add regression tests for: a late attempt after success, a cleared successful step, a u16 maximum step ID, and an `ActionFailedEvent`.
**Failure Observation Addendum**

`JournalEvent::StepFailed { run, seq, step, attempt }` is now included in failure observation. Recovery must retain the failed step's identity.

Observation accepts `StepStarted`, `StepFailed`, and `ActionFailedEvent`. Latest observed wins; matching `StepSucceeded` clears. Only terminal `RunFailed` is eligible. No numeric inference. Unknown `None` preserves eligibility.

Regression: `StepFailed17` with terminal `RunFailed` and no prior `StepStarted` yields `Some(17)`. All other accepted behavior preserved.

use super::analyze_retry;
use vb_core::{ActionId, RunId, SlotIdx, StepIdx};
use vb_storage::{EventSeq, JournalEvent};

fn started(step: u16) -> JournalEvent {
    JournalEvent::StepStarted {
        run: RunId::new(1),
        seq: EventSeq::new(1),
        step: StepIdx::new(step),
        attempt: 1,
    }
}

fn succeeded(step: u16) -> JournalEvent {
    JournalEvent::StepSucceeded {
        run: RunId::new(1),
        seq: EventSeq::new(2),
        step: StepIdx::new(step),
        output: SlotIdx::new(0),
    }
}

fn failed_action(step: u16) -> JournalEvent {
    JournalEvent::ActionFailedEvent {
        run: RunId::new(1),
        seq: EventSeq::new(3),
        step: StepIdx::new(step),
        action: ActionId::new(0),
        attempt: 1,
    }
}

fn failed_run() -> JournalEvent {
    JournalEvent::RunFailedEvent {
        run: RunId::new(1),
        seq: EventSeq::new(4),
        attempt: 1,
    }
}

fn cancelled_run() -> JournalEvent {
    JournalEvent::RunCancelled {
        run: RunId::new(1),
        seq: EventSeq::new(4),
        attempt: 1,
        reason: None,
    }
}

fn finished_run() -> JournalEvent {
    JournalEvent::RunFinished {
        run: RunId::new(1),
        seq: EventSeq::new(4),
        attempt: 1,
        result: SlotIdx::new(0),
    }
}

#[test]
fn retry_step_zero() {
    let a = analyze_retry(&[started(0), failed_run()]);
    assert!(a.can_retry);
    assert_eq!(a.failed_at_step, Some(0));
}

#[test]
fn retry_step_max() {
    let a = analyze_retry(&[started(u16::MAX), failed_run()]);
    assert!(a.can_retry);
    assert_eq!(a.failed_at_step, Some(u16::MAX));
}

#[test]
fn failed_run_after_matching_success_has_unknown_step() {
    let a = analyze_retry(&[started(u16::MAX), succeeded(u16::MAX), failed_run()]);
    assert!(a.can_retry);
    assert_eq!(a.failed_at_step, None);
    assert_eq!(a.last_successful_step, Some(u16::MAX));
}

#[test]
fn retry_last_started() {
    let a = analyze_retry(&[
        JournalEvent::ActionFailedEvent {
            run: RunId::new(1),
            seq: EventSeq::new(1),
            step: StepIdx::new(10),
            action: ActionId::new(0),
            attempt: 1,
        },
        JournalEvent::StepStarted {
            run: RunId::new(1),
            seq: EventSeq::new(2),
            step: StepIdx::new(8),
            attempt: 1,
        },
        failed_run(),
    ]);
    assert!(a.can_retry);
    assert_eq!(a.failed_at_step, Some(8));
}

#[test]
fn retry_failed_action() {
    let a = analyze_retry(&[failed_action(10), failed_run()]);
    assert!(a.can_retry);
    assert_eq!(a.failed_at_step, Some(10));
}

#[test]
fn no_retry_cancelled_or_finished() {
    let a1 = analyze_retry(&[started(5), cancelled_run()]);
    assert!(!a1.can_retry);
    assert_eq!(a1.failed_at_step, None);
    assert_eq!(a1.reason, "run did not fail (no retry needed)");
    let a2 = analyze_retry(&[started(5), finished_run()]);
    assert!(!a2.can_retry);
    assert_eq!(a2.failed_at_step, None);
    assert_eq!(a2.reason, "run did not fail (no retry needed)");
}

#[test]
fn no_retry_active_or_empty() {
    let a1 = analyze_retry(&[started(3)]);
    assert!(!a1.can_retry);
    assert_eq!(a1.failed_at_step, None);
    assert_eq!(a1.reason, "run did not fail (no retry needed)");
    let a2 = analyze_retry(&[]);
    assert!(!a2.can_retry);
    assert_eq!(a2.failed_at_step, None);
    assert_eq!(a2.reason, "run did not fail (no retry needed)");
}

#[test]
fn retry_explicit_step_failed() {
    let a = analyze_retry(&[
        JournalEvent::StepFailed {
            run: RunId::new(1),
            seq: EventSeq::new(1),
            step: StepIdx::new(17),
            attempt: 1,
        },
        failed_run(),
    ]);
    assert!(a.can_retry);
    assert_eq!(a.failed_at_step, Some(17));
    assert_eq!(a.last_successful_step, None);
}
