# Domain Model: Collect Primitive and Body Lowering

## Ubiquitous Language

| Term | Definition |
|------|------------|
| **Collect** | A scoped primitive that accumulates pages of items into a collector slot. Emits `CollectStart`, `CollectPage`, `CollectFinish` nodes. |
| **Body** | The sequence of steps nested inside a scoped primitive (collect, for_each, aggregate, repeat, parallel branch). |
| **Body Step** | The synthetic compiled-node step index assigned to the body content. For collect: `id + 1`. |
| **Synthetic Step** | A compiled IR step index generated by offset from the parent primitive's step index. Not present in source YAML. |
| **Source Step Index** | The 0-based ordinal of a step in the parsed YAML AST. Used for human-facing diagnostics. |
| **Compiled Step Index (`StepIdx`)** | The `u16` node identifier in the compiled `CompiledWorkflow` IR graph. |
| **`emit_single_body_set`** | Shared lowering dispatcher that validates `body.len() == 1`, asserts the single step is `Set`, and lowers it into a `CompiledNodeKind::Set`. |
| **Scoped Primitive** | A primitive that introduces a control-flow scope with synthetic steps: collect, for_each, aggregate/reduce, repeat, parallel branch. |
| **Diagnostic Index** | The step number reported to the user in `CompileError`. Must map to a source YAML step, never to a synthetic step. |

## Entities and Value Objects

### `CollectLowering` ( lowering context value object )
- `source: &str` — expression text for the collector slot
- `pages: Option<u32>` — page limit (default 1)
- `items: Option<u32>` — items per page (default 1)
- `body: &[StepAst]` — nested body steps (must be exactly one `Set` step)
- `next: Option<StepIdx>` — successor in compiled IR

### `StepIdx` ( value object )
- Newtype around `u16` with `checked_add(u16) -> Option<StepIdx>`
- `as_usize()` converts to `usize` for indexing
- Zero is the workflow entry step

### `StepAst` ( value object )
- Parsed YAML AST node for a single workflow step
- Contains `primitive: StepPrimitive` (e.g., `Set { value, ... }`)

## Invariants

1. **Body Cardinality Invariant**: Every scoped primitive body must contain exactly one `StepAst`.
2. **Body Primitive Invariant**: The single body step must be a `Set` primitive.
3. **Synthetic Step Monotonicity**: Synthetic step offsets (`+1`, `+2`, `+3`) must not overflow `u16::MAX`.
4. **Diagnostic Fidelity Invariant**: Compile errors arising from body validation must report the *source step index* (the step in the YAML where the primitive is declared), never a synthetic compiled step index.
5. **Index Consistency**: `index: usize` (AST ordinal) and `id: StepIdx` (IR node id) refer to the same logical step but live in different namespaces (AST vs IR).

## Aggregate: `CompiledNode` Graph

The lowering phase transforms a linear `Vec<StepAst>` into a directed `CompiledNode` graph.
- Each source step may expand to 1–N compiled nodes
- Synthetic steps are inserted between the primitive start and its continuation
- The `emit_single_body_set` dispatcher is shared across all scoped primitives

## Known Defect

`emit_single_body_set` receives `id: StepIdx` (the synthetic body step) and uses `id.as_usize()` for `CompileError::StepFieldShape.step`. This violates the Diagnostic Fidelity Invariant because the user sees a step number that does not exist in their source YAML.

## Affected Callers

| Caller | Synthetic `id` passed | Original source `index` available? |
|--------|----------------------|-----------------------------------|
| `lower_canonical_collect` | `body_step = id + 1` | `index: usize` |
| `lower_canonical_for_each` | `body_step = id + 1` | `index: usize` |
| `lower_canonical_aggregate` | `body_step = id + 1` | `index: usize` |
| `lower_canonical_repeat` | `body_step = id + 1` | `index: usize` |
| `lower_canonical_parallel` (branch) | `entry` (branch entry) | `branch_index: usize` |
