2: //! Contract tests for vb-3wn7x: pending action index maintenance in the
3: //! runtime journal path.
4: //!
5: //! Master §18 requires `index_action` to be the authoritative pending
6: //! action cursor. The defect captured under vb-3wn7x was that the
7: //! runtime's `append_journaled` / `append_strict` path only wrote the
8: //! `run_event` record, leaving the index keyspace out of sync with the
9: //! durable event log.
10: //!
11: //! These tests exercise every action-lifecycle event variant through
12: //! every admission path that previously missed the index update:
13: //!
14: //! - `FjallJournal::append_journaled` (journaled profile)
15: //! - `FjallJournal::append_strict` (strict profile)
16: //! - `FjallJournal::append_strict_batch` (atomic batch insert)
17: //! - `JournalWriteBatch::append_event` (cross-keyspace batch)
18: //! - `JournalWriterQueue::drain_all` (queued writer)
19: //!
20: //! Insert-side events:
21: //! - `JournalEvent::ActionScheduled`
22: //! - `JournalEvent::ActionScheduledTicket`
23: //!
24: //! Remove-side events:
25: //! - `JournalEvent::ActionCompletedEvent`
26: //! - `JournalEvent::ActionCompletedEnvelope`
27: //! - `JournalEvent::ActionFailedEvent`
28: //! - `JournalEvent::ActionAbandoned`
29: //!
30: //! No-op events (run/step/wait/ask/slot/lifecycle): leave the index
31: //! untouched.
32:
