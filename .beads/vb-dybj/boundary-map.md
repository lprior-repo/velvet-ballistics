# Boundary Map - vb-dybj State 3

## Pure Core Boundary

- `vb_core::RunId`
- `vb_core::WorkflowDigest`
- Other numeric newtypes generated by `numeric_id!`

Core responsibilities:

- Preserve exact constructor/accessor equality.
- Expose serde-compatible value objects.
- Avoid JSON/YAML/HTTP runtime interpretation.
- Keep invalid non-numeric/non-digest shapes outside the type.

## Storage Boundary

- `vb_storage::records::RecordKind`
- `vb_storage::records::RunHeaderStatus`
- `vb_storage::codec::{encode_record, decode_record}`
- `vb_storage::error::JournalError`

Storage responsibilities:

- Distinguish envelope `record_kind_u16` from Postcard enum bytes.
- Validate fixed 60-byte envelope before payload decode.
- Map short records to `UnexpectedEof`.
- Map payload Postcard decode failure to `PostcardDecodeFailed`.

## Test Boundary

- Future file: `crates/workspace_tests/tests/restate_postcard_newtype_compat_tests.rs`.
- Future Cargo target entry in `crates/workspace_tests/Cargo.toml`.

Test responsibilities:

- Freeze byte constants.
- Assert exact encoding and decoding behavior.
- Assert migration requirement in names/messages/comments.
- Avoid production hot-path dependencies.

## Dependency Boundary

- `postcard`: allowed compact binary serialization library.
- `serde`: allowed derive/data schema serialization for binary data.

Forbidden for this bead:

- `serde_json` wrapper path.
- Bilrost.
- Protobuf.
- Restate code/API/wire format copying.

## Imperative Shell

No runtime imperative shell behavior is in scope for this contract. Later test execution may invoke `cargo nextest` and `moon ci`, but State 3 does not run implementation gates.

## Async / Network / Time / FFI / Unsafe Boundaries

- Async: out of scope.
- Network/HTTP: forbidden for this compatibility path.
- Time: out of scope except existing record fields may contain timestamps in broader storage structs.
- FFI: out of scope.
- Unsafe: forbidden in first-party code and not needed for this bead.

## Parser Boundaries

- External byte slices must be treated as hostile until decoded by the selected surface.
- `WorkflowDigest` construction accepts `[u8; 32]`; any variable-length external digest bytes require prior length validation outside this type.
- Storage record bytes require header/payload validation before typed payload decode.

## Ownership Boundaries

- `vb_core` owns semantic identity types.
- `vb_storage` owns persisted record IDs and typed storage errors.
- `crates/workspace_tests` owns compatibility fixture assertions.
- A named migration owns intentional fixture changes.
