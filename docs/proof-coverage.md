# Proof Coverage

The repository ships three formal-verification layers — Kani (bounded model
checking), TLC (TLA+ state-machine model checking), and Verus (deductive Rust
proofs). The named `ci:` task in `.moon/tasks/all.yml` directly depends on the two Kani baseline tasks. Separately, `.moon.yml` lists `verify-kani`, `verify-tlc`, and `verify-verus` in its pipeline. These source declarations do not establish the evaluated `moon ci` graph or successful verification. The selections below describe configuration, not executed coverage.
