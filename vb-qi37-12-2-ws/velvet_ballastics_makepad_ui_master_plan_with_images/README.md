# velvet-ballastics Makepad UI Master Plan Bundle

This bundle contains the Makepad UI master-plan update plus the final Figma-ready design assets.

## Included

- `velvet-ballastics-MASTER-makepad-ui-update.md` — drop-in master-plan update.
- `design_assets/velvet_ballastics_figma_ready_tightened/png/` — 8 final 1920×1080 PNG screens.
- `design_assets/velvet_ballastics_figma_ready_tightened/svg/` — 8 editable SVG screens for Figma import.
- `design_assets/velvet_ballastics_figma_ready_tightened/velvet_ballastics_figma_ready_tightened_board.png` — full 8-screen board.
- `design_assets/velvet_ballastics_figma_ready_tightened/figma_makepad_notes.md` — Figma + Makepad handoff notes.

## Screen set

1. Execution Observatory Overview
2. Workflow Graph Authoring
3. Execution Details Graph View
4. Verification Certificate View
5. Replay Theater
6. Incident Failure Console
7. Action Registry / Contract Inspector
8. Storage / Journal Doctor + AI Context

## Figma import

Import the SVG files for editable vector layers. Use the PNG files as pixel-reference previews. The board PNG is useful for design reviews.

## Makepad implementation note

The master-plan update defines the Makepad implementation contract, including typed UI artifacts, screen taxonomy, motion rules, token pipeline, snapshot gates, and acceptance criteria. Figma is the visual reference; Makepad Live Design + Rust widgets are the implementation source of truth.
