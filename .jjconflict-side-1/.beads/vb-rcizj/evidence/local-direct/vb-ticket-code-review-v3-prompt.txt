# Contract: Resolve nine retry and attempt integration failures using issued action-ticket authority

## Authority
Master plan §18 (Action Execution Model), §44 (Runtime Verification), and the accepted runtime lifecycle acceptance contract.

## Scope
Own `crates/vb_runtime/tests/durable_retry_red_phase.rs` and `crates/vb_runtime/tests/vb_jggy_lifecycle_tests.rs` entirely. Repair production preflight functions only if a genuinely valid issued-ticket path fails; preserve authority, identity, capacity, sequence, idempotency, and all existing attempt validation semantics.

## Requirements

1. **Issued-ticket acceptance**: A ticket with valid run/step/action identity, correct attempt (matches current counter), and valid idempotency key must be accepted for completion or failure. Success requires the EXACT pending ticket to match the incoming ticket (full equality).
2. **Stale-attempt rejection**: A ticket with attempt lower than the current action_attempts value must be rejected with `StaleAttempt { incoming, current }` before any journal mutation. This applies only when all other identity fields (run, step, action, capacity) match the pending ticket and the canonical idempotency key is valid.
3. **Future-attempt rejection**: A ticket with attempt higher than the current action_attempts value must be rejected with `InvalidActionCompletion` (G005).
4. **Forged/invalid identity rejection**: A ticket with wrong run, step, or action identity must be rejected with `InvalidActionCompletion` before any state or journal mutation.
5. **Zero attempt rejection**: A ticket with attempt=0 must be rejected with `AttemptBeyondMax`.
6. **Capacity validation**: A ticket with attempt > capacity or capacity=0 must be rejected with `AttemptBeyondMax`.
7. **Journal mutation ordering**: All ticket validation must occur before any durable journal append.
8. **Attempt tracking**: action_attempts[step] must be updated monotonically and never decrease.
9. **Retry PC reset**: On retryable failure, the PC must reset to the failed step.
10. **Idempotency key validation**: Any ticket classification (including StaleAttempt) must use the production canonical idempotency key predicate; tickets with invalid keys remain rejected regardless of other fields.

## Test acceptance criteria

- All 9 retained failures (3 from durable_retry_red_phase, 6 from vb_jggy_lifecycle_tests) must pass.
- Existing expected errors must not be weakened; tests must still exercise StaleAttempt, AttemptBeyondMax, InvalidActionCompletion, etc.
- Positive tests must assert exact event/value/attempt behavior.
- Negative tests must verify journal state is unchanged.
- No new unwrap/expect/panic/unchecked operations.

# Contract Error Precedence Addendum (vb-rcizj)

This addendum documents the actual production error precedence in the shard
lifecycle command handlers. The original contract incorrectly assumed that
attempt-related errors (StaleAttempt, AttemptBeyondMax) would be returned for
forged tickets. The actual behavior checks ticket ownership/identity FIRST,
before any attempt validation.

## Production Validation Order

### For ActionCompleted (handle_action_completion, lifecycle/chunk_001.rs:568)

1. **require_pending_action_ownership(ticket)** — lifecycle/chunk_004.rs:37
   - If run does not exist → `RunNotFound`
   - If run exists but no pending ticket → `InvalidActionCompletion`
   - If run exists but pending ticket ≠ incoming ticket → `InvalidActionCompletion`
   - Only passes when exact ticket match: run, step, action, attempt, capacity, seq, idempotency_key

2. **run_state_get(run)** — retrieves run state (fails if run disappeared)

3. **preflight_action_completion(state, ticket, output)** — lifecycle/chunk_003_chunks/chunk_001_preflight_completion.rs:59
   - validate_action_completion(state, ticket) → calls validate_ticket_attempt
   - validate_ticket_attempt (helpers.rs:118) checks:
     - attempt=0 or capacity=0 or attempt > capacity → `AttemptBeyondMax`
     - attempt < current counter → `StaleAttempt`
     - attempt > current counter → `InvalidActionCompletion` (future attempt)
   - reject_invalid_ticket_key
   - Output slot, taint, size, and contract validation

### For ActionFailed (handle_action_failure, lifecycle/chunk_001.rs:651)

Identical ordering: ownership check first, then preflight validation.

## Implications for Testing

- **Wrong run/step/action identity** → `InvalidActionCompletion` (or `RunNotFound` if run missing)
  - NOT `StaleAttempt` or `AttemptBeyondMax`
- **Capacity=0 or attempt=0 with correct identity** → `AttemptBeyondMax` (after ownership passes)
- **Stale attempt with correct identity** → `StaleAttempt` (after ownership passes)
- **Future attempt with correct identity** → `InvalidActionCompletion` (after ownership passes)

## Source Evidence

- `require_pending_action_ownership` in lifecycle/chunk_004.rs:37-44
- `validate_ticket_attempt` in helpers.rs:118-138
- Command handling in lifecycle/chunk_001.rs:568, 651

## Master Plan Alignment

Master plan §72 mandates `StaleAttempt` only for actual stale attempts with
matching identity. This addendum preserves all pre-existing behavior and old
assertions; it corrects the contract's expectation about forged tickets.

## Additional Finding: Attempt/Capacity Validation Order

Production validates ticket ownership (exact match) BEFORE attempt/capacity
validation. This means:

- Forged tickets with attempt=0 → `InvalidActionCompletion` (ownership fails first)
- Forged tickets with capacity=0 → `InvalidActionCompletion` (ownership fails first)
- Forged tickets with attempt > capacity → `InvalidActionCompletion` (ownership fails first)

`AttemptBeyondMax` is only returned for tickets that PASS ownership validation
(exact pending ticket match) but have invalid attempt/capacity values. This
scenario requires the exact same run/step/action/seq/idempotency_key as the
pending ticket, differing only in attempt or capacity.

This means the contract's assertion that "a ticket with attempt=0 must be
rejected with AttemptBeyondMax" is only true for the exact pending ticket with
attempt=0, not for any forged ticket with attempt=0.

## Updated Test Expectations

For the three failing ticket_authority_matrix tests, the expected errors are:
- action_completed_attempt_zero_returns_beyond_max → expects `InvalidActionCompletion` (not `AttemptBeyondMax`)
- action_completed_capacity_zero_returns_beyond_max → expects `InvalidActionCompletion` (not `AttemptBeyondMax`)
- action_failed_attempt_zero_returns_beyond_max → expects `InvalidActionCompletion` (not `AttemptBeyondMax`)

These tests will be renamed and updated to reflect the actual production
behavior.

impl Shard {
    fn reserve_cancel_kill_terminalization(&mut self, run: RunId) -> RuntimeResult<()> {
        self.reserve_checked_out_run_slot(run)?;
        self.reserve_terminal_run_slot(run)
    }

    fn append_cancel_terminal_events(
        &mut self,
        run: RunId,
        reason: Option<String>,
    ) -> RuntimeResult<()> {
        self.append_terminal_events_with_pending_action(
            run,
            RuntimeJournalEvent::RunCancelled { run, reason },
        )
    }

    fn append_kill_terminal_events(&mut self, run: RunId) -> RuntimeResult<()> {
        self.append_terminal_events_with_pending_action(run, RuntimeJournalEvent::RunKilled { run })
    }

    fn append_terminal_events_with_pending_action(
        &mut self,
        run: RunId,
        terminal: RuntimeJournalEvent,
    ) -> RuntimeResult<()> {
        match self.pending_action_get(run) {
            Some(ticket) if ticket.run == run => self.append_journal_events_atomically([
                RuntimeJournalEvent::ActionAbandoned { ticket },
                terminal,
            ]),
            Some(_) => Err(RuntimeError::InvalidActionCompletion),
            None => self.append_journal_event(terminal),
        }
    }

    fn require_pending_action_ownership(&self, ticket: ActionTicket) -> RuntimeResult<()> {
        if !self.run_state_contains(ticket.run) {
            return Err(RuntimeError::RunNotFound);
        }
        match self.pending_action_get(ticket.run) {
            Some(pending) if pending == ticket => Ok(()),
            Some(pending)
                if ticket.attempt > 0
                    && ticket.attempt < pending.attempt
                    && ticket.run == pending.run
                    && ticket.step == pending.step
                    && ticket.action == pending.action
                    && ticket.capacity == pending.capacity
                    && vb_core::action::action_ticket_has_valid_key(ticket)
                    && ticket.seq <= pending.seq =>
            {
                Err(RuntimeError::StaleAttempt {
                    incoming: ticket.attempt,
                    current: pending.attempt,
                })
            }
            Some(_) | None => Err(RuntimeError::InvalidActionCompletion),
        }
    }

    fn require_legacy_pending_action_ownership(
        &self,
        run: RunId,
        step: StepIdx,
    ) -> RuntimeResult<ActionTicket> {
        if !self.run_state_contains(run) {
            return Err(RuntimeError::RunNotFound);
        }
        match self.pending_action_get(run) {
            Some(pending) if pending.run == run && pending.step == step => Ok(pending),
            Some(_) | None => Err(RuntimeError::InvalidActionCompletion),
        }
    }
}

// tests/ticket_stale_guards.rs
// Tests that stale (superseded) action tickets are rejected on delivery.

use super::*;
use std::sync::Arc;

#[derive(Debug)]
enum StaleTamper {
    Step,
    Action,
    Capacity,
    Key,
    Sequence,
}

#[derive(Debug)]
enum Delivery {
    Completion,
    Failure,
}

fn check(tamper: &StaleTamper, delivery: &Delivery) -> Result<(), Box<dyn std::error::Error>> {
    let journal = Arc::new(VolatileRuntimeJournal::new());
    let mut shard = Shard::new_with_journal(small_config(), journal.clone());

    let workflow = retry_workflow().ok_or("no retry workflow")?;
    let run = RunId::new(100);
    submit_with_contracts(&shard, run, workflow);
    assert_eq!(shard.tick(), Ok(true));
    let ticket1 = shard.pending_action_get(run).ok_or("missing ticket1")?;
    assert_eq!(ticket1.attempt, 1);

    shard.enqueue(ShardCommand::ActionFailed {
        ticket: ticket1,
        failure: retryable_failure(),
    })?;
    assert_eq!(shard.tick(), Ok(true));
    let ticket2 = shard.pending_action_get(run).ok_or("missing ticket2")?;

    shard.enqueue(ShardCommand::ActionFailed {
        ticket: ticket2,
        failure: retryable_failure(),
    })?;
    assert_eq!(shard.tick(), Ok(true));
    let ticket3 = shard.pending_action_get(run).ok_or("missing ticket3")?;

    assert_eq!(ticket2.attempt, 2);
    assert_eq!(ticket3.attempt, 3);

    let current_ticket = ticket3;
    let snap_before = journal.snapshot()?;

    let frame_before = &shard.run_state_get(run).ok_or("frame missing")?.frame;
    let pc_before = frame_before.pc();
    let slot0_before = *frame_before.read_slot(SlotIdx::ZERO)?;
    let slot1_before = *frame_before.read_slot(SlotIdx::new(1))?;
    let taint0_before = frame_before.read_taint(SlotIdx::ZERO)?;
    let taint1_before = frame_before.read_taint(SlotIdx::new(1))?;

    let mut stale = ticket2;
    match tamper {
        StaleTamper::Step => {
            stale.step = StepIdx::new(99);
        }
        StaleTamper::Action => {
            stale.action = ActionId::new(99);
            stale.idempotency_key =
                vb_core::action::compute_action_idempotency_key(stale.run, stale.seq, stale.action);
        }
        StaleTamper::Capacity => {
            stale.capacity = stale.capacity.checked_add(1).ok_or("cap overflow")?;
        }
        StaleTamper::Key => {
            stale.idempotency_key ^= 1;
        }
        StaleTamper::Sequence => {
            let seq_plus = current_ticket
                .seq
                .get()
                .checked_add(1)
                .ok_or("seq overflow")?;
            stale.seq = SeqNo::new(seq_plus);
            stale.idempotency_key =
                vb_core::action::compute_action_idempotency_key(stale.run, stale.seq, stale.action);
        }
    }

    let command = match delivery {
        Delivery::Completion => ShardCommand::ActionCompleted {
            ticket: stale,
            output: ActionOutputReady {
                output_slot: SlotIdx::ZERO,
                value: SlotValue::I64(7),
                taint: Taint::Clean,
                encoded_len: 3,
            },
        },
        Delivery::Failure => ShardCommand::ActionFailed {
            ticket: stale,
            failure: non_retryable_failure(),
        },
    };
    shard.enqueue(command)?;
    assert_eq!(
        shard.tick(),
        Err(RuntimeError::InvalidActionCompletion),
        "{tamper:?} via {delivery:?}"
    );

    let snap_after = journal.snapshot()?;
    assert_eq!(snap_before, snap_after);

    let current_pending = shard.pending_action_get(run).ok_or("current ticket gone")?;
    assert_eq!(current_pending, current_ticket);

    let frame_after = &shard.run_state_get(run).ok_or("frame gone after")?.frame;
    assert_eq!(pc_before, frame_after.pc());
    assert_eq!(slot0_before, *frame_after.read_slot(SlotIdx::ZERO)?);
    assert_eq!(slot1_before, *frame_after.read_slot(SlotIdx::new(1))?);
    assert_eq!(taint0_before, frame_after.read_taint(SlotIdx::ZERO)?);
    assert_eq!(taint1_before, frame_after.read_taint(SlotIdx::new(1))?);

    Ok(())
}

fn contract_required_capability(action: ActionId) -> Capability {
    Capability::new("__contract_required__".into(), action)
}

fn max_do_action(workflow: &CompiledWorkflow) -> Option<ActionId> {
    let mut index = 0u16;
    let count = workflow.node_count();
    let mut max_action: Option<ActionId> = None;
    while index < count {
        if let Some(node) = workflow.node(StepIdx::new(index)) {
            if let CompiledNodeKind::Do { action, .. } = node.kind {
                max_action = match max_action {
                    Some(current) if current.get() >= action.get() => Some(current),
                    _ => Some(action),
                };
            }
        }
        index = index.saturating_add(1);
    }
    max_action
}

fn action_contract(action: ActionId, required: bool) -> ActionContract {
    let required_capabilities = if required {
        Box::from([contract_required_capability(action)])
    } else {
        Box::from([])
    };
    ActionContract {
        id: action,
        name: ActionName::new("test-action").unwrap(),
        input_slot_count: 1,
        output_slot_count: 1,
        max_input_bytes: 1024,
        max_output_bytes: 1024,
        timeout_ms: 5000,
        idempotency: Idempotency::DeterministicPure,
        side_effect: SideEffect::None,
        retry_safety: RetrySafety::Safe,
        required_capabilities,
    }
}

fn contracts_through(action: ActionId) -> Box<[ActionContract]> {
    let target = action.get();
    let mut contracts = Vec::with_capacity(usize::from(target).saturating_add(1));
    let mut id = 0u16;
    loop {
        let current = ActionId::new(id);
        contracts.push(action_contract(current, id == target));
        if id == target {
            break;
        }
        id = id.saturating_add(1);
    }
    contracts.into_boxed_slice()
}

    shard: &Shard,
    run: RunId,

}

        idempotency_key: vb_core::action::compute_action_idempotency_key(run, seq, action),
        capacity,
    }
}

        encoded_len: 0,
    }

    ActionFailure {
        code: ActionFailureCode::Rejected,
        retry_policy: VbRetryPolicy::NonRetryable,
        taint: Taint::Clean,
        detail: None,
        encoded_len: 0,
    }
}

/// B21: handle_action_completion rejects stale attempt BEFORE journal write
#[test]
fn stale_attempt_completion_rejected_before_journal_write() -> Result<(), Box<dyn std::error::Error>>
{
    let journal = std::sync::Arc::new(VolatileRuntimeJournal::new());
    let shared = journal.clone();
    let mut shard = Shard::new_with_journal(small_config(), shared);

    let Some(wf) = retry_workflow() else {
        return Err("missing retry workflow fixture".into());
    };
    let run = RunId::new(20);

    // Submit and drive to first action
    submit_with_contracts(&shard, run, wf);
    assert_eq!(shard.tick(), Ok(true));

    // Drive failure to advance to ticket 2
    let ticket1 = shard
        .pending_action_get(run)
        .ok_or("action should have issued ticket 1")?;
    assert_eq!(ticket1.attempt, 1, "ticket1 should have attempt=1");
    assert_eq!(
        shard.enqueue(ShardCommand::ActionFailed {
            ticket: ticket1,
            failure: retryable_failure(),
        }),
        Ok(())
    );
    assert_eq!(shard.tick(), Ok(true));

    // Capture real ticket 2 (will become stale)
    let ticket2 = shard
        .pending_action_get(run)
        .ok_or("action should have issued ticket 2")?;
    assert_eq!(ticket2.attempt, 2, "ticket2 should have attempt=2");
    let ticket2_attempt = ticket2.attempt;
    assert_eq!(ticket2_attempt, 2, "ticket2 should have attempt=2");

    // Drive failure to advance to ticket 3
    assert_eq!(
        shard.enqueue(ShardCommand::ActionFailed {
            ticket: ticket2,
            failure: retryable_failure(),
        }),
        Ok(())
    );
    assert_eq!(shard.tick(), Ok(true));

    // Now current attempt is 3, but we'll try to complete with the saved ticket 2 attempt
    let ticket3 = shard
        .pending_action_get(run)
        .ok_or("action should have issued ticket 3")?;
    assert_eq!(ticket3.attempt, 3, "ticket3 should have attempt=3");

    // Capture state before stale completion attempt
    let journal_before = journal.snapshot()?;
    let counters_before = shard.counters().snapshot();

    // Attempt stale completion with saved ticket 2 attempt number
    let stale_ticket = ticket2;
    let output = ActionOutputReady {
        output_slot: SlotIdx::ZERO,
        value: SlotValue::I64(7),
        taint: Taint::Clean,
        encoded_len: 3,
    };
    assert_eq!(
        shard.enqueue(ShardCommand::ActionCompleted {
            ticket: stale_ticket,
            output,
        }),
        Ok(())
    );
    assert_eq!(
        shard.tick(),
        Err(RuntimeError::StaleAttempt {
            incoming: ticket2_attempt,
            current: ticket3.attempt,
        })
    );

    // Verify NO new journal events were written
    let journal_after = journal.snapshot()?;
    assert_eq!(
        journal_before, journal_after,
        "Journal must not be mutated when stale attempt is rejected"
    );

    // Verify counters unchanged
    let counters_after = shard.counters().snapshot();
    assert_eq!(
        counters_before.runs_completed, counters_after.runs_completed,
        "runs_completed counter must not change on stale rejection"
    );
    assert_eq!(
        counters_before.runs_failed, counters_after.runs_failed,
        "runs_failed counter must not change on stale rejection"
    );

    Ok(())
}

#[derive(Clone, Copy, Debug)]
enum Tamper {
    MissingRun,
    OtherRun,
    Step,
    Action,
    ZeroAttempt,
    FutureAttempt,
    ZeroCapacity,
    Capacity,
    Key,
    Sequence,
}
const CASES: [Tamper; 10] = [
    Tamper::MissingRun,
    Tamper::OtherRun,
    Tamper::Step,
    Tamper::Action,
    Tamper::ZeroAttempt,
    Tamper::FutureAttempt,
    Tamper::ZeroCapacity,
    Tamper::Capacity,
    Tamper::Key,
    Tamper::Sequence,
];
#[derive(Clone, Copy, Debug)]
enum Delivery {
    Completion,
    Failure,

fn submit(shard: &mut Shard, run: RunId) -> TestResult<ActionTicket> {
    shard.enqueue(ShardCommand::SubmitWithContracts {
        run,
        workflow: setconst_do_workflow(0)?,
        caps: CapabilitySet::empty(),
        action_contracts: Box::from([make_contract(0, "valid")?]),
    })?;
    assert_eq!(shard.tick(), Ok(true));
    shard
        .pending_action_get(run)
        .ok_or_else(|| "missing issued ticket".into())
}
fn corrupted(mut ticket: ActionTicket, case: Tamper, other: RunId) -> TestResult<ActionTicket> {
    match case {
        Tamper::MissingRun => ticket.run = RunId::new(99999),
        Tamper::OtherRun => ticket.run = other,
        Tamper::Step => ticket.step = StepIdx::new(99),
        Tamper::Action => ticket.action = ActionId::new(99),
        Tamper::ZeroAttempt => ticket.attempt = 0,
        Tamper::FutureAttempt => {
            ticket.attempt = ticket.attempt.checked_add(1).ok_or("attempt overflow")?
        }
        Tamper::ZeroCapacity => ticket.capacity = 0,
        Tamper::Capacity => {
            ticket.capacity = ticket.capacity.checked_add(1).ok_or("capacity overflow")?
        }
        Tamper::Key => ticket.idempotency_key ^= 1,
        Tamper::Sequence => {
            ticket.seq = SeqNo::new(ticket.seq.get().checked_add(1).ok_or("sequence overflow")?);
            ticket.idempotency_key = vb_core::action::compute_action_idempotency_key(
                ticket.run,
                ticket.seq,
                ticket.action,
            );
        }
    }
    Ok(ticket)
}
fn check_case(case: Tamper, delivery: Delivery) -> TestResult<()> {
    let journal = Arc::new(VolatileRuntimeJournal::new());
    let mut shard = Shard::new_with_journal(
        ShardConfig {
            command_queue_capacity: 64,
            trace_capacity: 64,
            step_budget_per_tick: 4,
            max_active_runs: 4,
            policy: vb_core::policy::RuntimePolicy::Relaxed,
        },
        journal.clone(),
    );
    let run = RunId::new(500);
    let other = RunId::new(501);
    let original = submit(&mut shard, run)?;
    let second = submit(&mut shard, other)?;
    let before = journal.snapshot()?;
    let state = shard
        .run_state_get(run)
        .ok_or("missing run before rejection")?;
    let pc = state.frame.pc();
    let value = *state.frame.read_slot(SlotIdx::ZERO)?;
    let taint = state.frame.read_taint(SlotIdx::ZERO)?;
    let ticket = corrupted(original, case, other)?;
    let command = match delivery {
        Delivery::Completion => ShardCommand::ActionCompleted {
            ticket,
            output: ActionOutputReady {
                output_slot: SlotIdx::new(1),
                value: SlotValue::I64(100),
                taint: Taint::Clean,
                encoded_len: 3,
            },
        },
        Delivery::Failure => ShardCommand::ActionFailed {
            ticket,
            failure: non_retryable_failure(),
        },
    };
    shard.enqueue(command)?;
    let expected = match case {
        Tamper::MissingRun => RuntimeError::RunNotFound,
        _ => RuntimeError::InvalidActionCompletion,
    };
    assert_eq!(shard.tick(), Err(expected), "{case:?} via {delivery:?}");
    assert_eq!(journal.snapshot()?, before, "{case:?} via {delivery:?}");
    assert_eq!(shard.pending_action_get(run), Some(original));
    assert_eq!(shard.pending_action_get(other), Some(second));
    let state = shard
        .run_state_get(run)
        .ok_or("missing run after rejection")?;
    assert_eq!(state.frame.pc(), pc);
    assert_eq!(state.frame.read_slot(SlotIdx::ZERO)?, &value);
    assert_eq!(state.frame.read_taint(SlotIdx::ZERO)?, taint);
    Ok(())
}
#[test]
fn completion_rejects_tampering_without_journal_or_run_mutation() -> TestResult<()> {
    for case in CASES {
        check_case(case, Delivery::Completion)?;
    }
    Ok(())
}
#[test]
fn failure_rejects_tampering_without_journal_or_run_mutation() -> TestResult<()> {
    for case in CASES {
        check_case(case, Delivery::Failure)?;
    }
    Ok(())
}
